# MIPS Fundamentals

#### CS 240 Assignment 3

I solved [FizzBuzz](https://leetcode.com/problems/fizz-buzz/) on LeetCode and converted each step of my solution into MIPS code. I added some functionality like user input. Every instruction was found on the documentation [here](https://asm-editor.specy.app/documentation/mips). Certain code structure was understood using examples from [geeksforgeeks](), and I just tried to relate different ideas from C++ into MIPS.
